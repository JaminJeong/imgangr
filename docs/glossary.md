# 비전공자를 위한 프론트엔드 & 백엔드 용어 설명서 (Glossary)

본 문서는 소프트웨어 개발이나 웹 기술(프론트엔드, 백엔드)에 익숙하지 않은 분들도 **임장기록(Imgangr)** 프로젝트의 기술 문서와 동작 원리를 쉽게 이해할 수 있도록 일상적인 비유와 친절한 설명을 담은 용어집입니다.

---

## 🍽️ 먼저 이해하는 프론트엔드 vs 백엔드

소프트웨어를 **식당(음식점)**에 비유하면 쉽게 이해할 수 있습니다.

```
┌──────────────────────────────────────┐     ┌──────────────────────────────────────┐
│        프론트엔드 (Frontend)         │     │         백엔드 (Backend)             │
│            [식당 홀 & 테이블]        │     │          [식당 주방 & 창고]          │
│                                      │     │                                      │
│  • 손님이 직접 눈으로 보는 인테리어  │     │  • 손님 눈에 보이지 않는 주방        │
│  • 메뉴판, 식기, 의자, 터치 주문기   │ ──► │  • 주문을 받아 요리를 만드는 요리사 │
│  • 손님이 버튼을 누르고 화면을 조작  │ ◄── │  • 식자재를 보관하는 냉장고/창고     │
│                                      │     │  • 매출 장부와 회원 명부 관리        │
└──────────────────────────────────────┘     └──────────────────────────────────────┘
```

- **프론트엔드 (Frontend)**: 스마트폰 화면에 보이는 디자인, 지도, 버튼, 팝업창 등 **사용자가 직접 눈으로 보고 손으로 만지는 모든 영역**입니다.
- **백엔드 (Backend)**: 사용자의 눈에는 보이지 않지만, 뒤편에서 **데이터를 안전하게 저장하고 가공하여 전달해 주는 서버 및 데이터베이스 시스템**입니다.

### 💡 임장기록(v1.0)의 특별한 점: "도시락(오프라인 우선) 방식"
보통의 웹사이트(예: 네이버, 인스타그램)는 주방(서버)과 계속 통신해야만 작동합니다.  
하지만 임장기록은 **"내 폰 안에 작은 주방과 냉장고를 함께 싸 들고 다니는 도시락"**처럼 설계되었습니다.  
따라서 신축 공사현장이나 지하 주차장처럼 **인터넷이 터지지 않는 곳에서도 내 폰 안에서 모든 기록과 지도가 안전하게 작동**합니다.

## 📱 1. 프론트엔드 (Frontend) 핵심 용어

### 웹의 기본 3요소 (HTML / CSS / JavaScript)
집을 짓는 과정에 비유할 수 있습니다.
- **HTML (뼈대)**: 집의 기둥과 벽, 방의 구조를 잡는 기술입니다. 웹 화면에 글자, 버튼, 지도 상자가 들어갈 자리를 만듭니다.
- **CSS (인테리어/디자인)**: 벽지 색상, 가구 배치, 글자 크기, 모바일 화면에 맞춘 레이아웃을 예쁘게 꾸미는 스타일링 기술입니다.
- **JavaScript (가전제품/전기배선)**: 스위치를 누르면 불이 켜지듯, 버튼을 눌렀을 때 팝업이 뜨고 GPS를 켜서 선을 긋는 등 **실제 살아 움직이게 만드는 프로그래밍 언어**입니다.

---

### 화면 및 개발 방식 관련 용어

- **SPA (Single Page Application, 단일 페이지 앱)**:
  - 보통의 웹사이트는 메뉴를 누를 때마다 화면이 하얗게 깜빡이며 새 페이지를 불러옵니다.
  - SPA는 화면을 새로고침하지 않고, 스마트폰 앱처럼 필요한 부분만 매끄럽게 교체하여 보여주는 방식입니다.
- **Vanilla JS (바닐라 자바스크립트)**:
  - '바닐라 아이스크림'이 아무것도 첨가되지 않은 순수한 맛을 뜻하듯, React나 Vue 같은 **복잡한 외부 도구(프레임워크)를 쓰지 않고 순수한 웹 표준 자바스크립트만으로 개발하는 방식**을 말합니다. 매우 가볍고 빠르며 설치가 필요 없습니다.
- **바텀시트 (Bottom Sheet)**:
  - 모바일 화면 아래쪽에서 서랍처럼 슥 올라오는 모달 창입니다. 한 손으로 스마트폰을 쥐고 걸어 다니면서도 엄지손가락으로 쉽게 닫고 입력할 수 있습니다.
- **XSS (Cross-Site Scripting, 크로스 사이트 스크립팅) 방지**:
  - 악의적인 사용자가 메모란에 해킹용 코드를 몰래 적어 넣는 것을 막기 위해, 입력된 글자를 안전한 일반 텍스트로 변환(Escape)하는 보안 기법입니다.

---

### 지도 및 위치 관련 용어

- **Leaflet.js (리플렛)**:
  - 웹 브라우저 위에 움직이는 지도를 띄워주는 매우 가볍고 대중적인 오픈소스 지도 소프트웨어입니다. 손가락으로 지도를 확대/축소하고 마커를 찍을 수 있게 돕습니다.
- **OpenStreetMap (OSM, 오픈스트리트맵)**:
  - 누구나 무료로 사용할 수 있는 '위키피디아' 같은 전 세계 오픈소스 지도 데이터입니다.
- **폴리라인 (Polyline)**:
  - 지도 위에 사용자가 걸어간 발자취를 따라 점들을 이어 만든 **파란색 이동 경로 선**을 말합니다.
- **Haversine (하버사인) 공식**:
  - 지구가 평면이 아니라 둥근 구(공 모양) 형태이기 때문에, 지도 위의 두 좌표(위도·경도) 사이의 **실제 직선거리(미터 단위)**를 정확하게 구해내는 수학 공식입니다.

---

### 브라우저 기능 (Web API) 관련 용어

- **Web API (웹 API)**:
  - 브라우저가 자바스크립트에게 스마트폰의 고급 하드웨어 부품(위치 센서, 마이크, 카메라 등)을 빌려 쓸 수 있도록 열어둔 연결 통로입니다.
- **Geolocation API (위치 정보 인터페이스)**:
  - 스마트폰에 내장된 GPS 칩셋으로부터 현재 나의 위도와 경도를 실시간으로 가져오는 기술입니다.
- **IndexedDB (인덱스드디비)**:
  - 웹 브라우저 내부에 내장된 **'내 폰 안의 대용량 금고(데이터베이스)'**입니다. 수천 개의 GPS 좌표, 임장 메모, 사진들을 인터넷 연결 없이도 영구 보관할 수 있습니다.
- **MediaRecorder API (미디어 레코더)**:
  - 스마트폰 마이크를 통해 들어오는 음성을 녹음하여 디지털 음성 파일(WebM 등)로 변환해 주는 브라우저 기능입니다.
- **Base64 (DataURL)**:
  - 사진이나 음성 같은 미디어 파일은 원래 컴퓨터 0과 1 바이너리 데이터입니다. 이를 텍스트 형태의 영문/숫자 긴 문자열로 변환하여 브라우저 금고(IndexedDB)에 문서처럼 쉽게 저장할 수 있게 만든 형식입니다.

## 🖥️ 2. 백엔드 & 인프라 (Backend & Infrastructure) 핵심 용어

### 서버 및 배포 관련 용어

- **웹 서버 (Web Server)**:
  - 사용자가 주소창에 `http://...`를 입력했을 때, 저장되어 있던 웹 페이지 파일(HTML, CSS, JS)을 찾아서 손님의 스마트폰 브라우저로 쏴주는 배달원 컴퓨터/소프트웨어입니다.
- **Nginx (엔진엑스)**:
  - 수많은 접속자가 몰려도 매우 빠르고 안정적으로 웹 파일을 서빙해 주는 세계 최고 수준의 고성능 웹 서버 소프트웨어입니다.
- **Docker (도커) & 컨테이너 (Container)**:
  - 프로그램과 그 프로그램이 실행되는 데 필요한 모든 환경(OS 부품, 웹 서버 등)을 하나의 **'규격화된 택배 상자(컨테이너)'**로 포장하는 기술입니다. 내 컴퓨터에서 잘 돌아가면 다른 어떤 서버 컴퓨터에 가져가도 똑같이 완벽하게 돌아갑니다.
- **Docker Compose (도커 컴포즈)**:
  - 여러 개의 도커 상자를 명령어 한 줄(`docker compose up`)로 한꺼번에 시동 걸고 관리하는 마법 리모컨입니다.
- **Gzip (지집) 압축**:
  - 파일을 인터넷으로 보낼 때 크기를 알집처럼 꽉 압축해서 전송하는 기술입니다. 모바일 데이터 소모를 줄이고 화면이 뜨는 속도를 빠르게 만듭니다.
- **캐시 (Cache)**:
  - 이미 한 번 다운로드한 지도 로고나 스타일 파일을 스마트폰 임시 저장소에 기억해 두고, 다음 접속 때 다시 다운로드하지 않고 즉시 꺼내 쓰는 고속 로딩 기술입니다.

---

### 네트워크 및 보안 용어

- **HTTPS & SSL/TLS**:
  - 주소창 옆에 달리는 초록색/자물쇠 아이콘입니다. 사용자의 스마트폰과 서버 사이의 통신을 암호화하여 중간에서 해커가 엿보거나 변조하지 못하게 지켜줍니다.
- **보안 컨텍스트 (Secure Context)**:
  - 웹 브라우저의 보안 규칙입니다. **GPS 위치 정보나 마이크 음성 녹음** 같은 사생활과 밀접한 기능은 반드시 안전한 **HTTPS** 주소에서만 동작하도록 강제합니다. (개발용 `localhost` 제외)

---

### 차세대(v2.0) 백엔드 확장 관련 용어

- **REST API (레스트 에이피아이)**:
  - 프론트엔드(스마트폰 앱)와 백엔드(원격 서버)가 인터넷을 통해 서로 데이터를 주고받기 위해 약속한 **표준 대화 규칙**입니다. (예: "새 세션 저장해 줘", "내 과거 임장 목록 줘")
- **JSON (제이슨)**:
  - 컴퓨터끼리 데이터를 주고받을 때 읽기 쉽도록 중괄호`{ "지역명": "강남구", "별점": 5 }` 형태로 정리한 만국 공통 데이터 표기법입니다.
- **RDBMS (관계형 데이터베이스)** & **PostgreSQL (포스트그레스큐엘)**:
  - 엑셀 시트처럼 행과 열이 있는 표 형태로 데이터를 안전하고 규칙성 있게 보관하는 대표적인 기업용 데이터베이스 시스템입니다.
- **PostGIS (포스트지아이에스)**:
  - PostgreSQL 데이터베이스에 **지도/공간 계산 능력**을 더해주는 확장 기능입니다. 복잡한 이동 경로 선(`LineString`)이나 특정 단지 경계 구역(`Polygon`)을 저장하고 계산할 수 있습니다.
- **오브젝트 스토리지 (Object Storage - AWS S3 / Cloudflare R2)**:
  - 고화질 사진이나 긴 음성 녹음 파일처럼 덩치가 큰 데이터를 무제한으로 저렴하고 안전하게 보관해 주는 클라우드 전용 대형 물류창고입니다.
- **Presigned URL (사전 서명된 주소)**:
  - 사용자가 사진을 올릴 때 무거운 서버를 거치지 않고, 클라우드 창고(S3/R2)로 곧바로 안전하게 직배송할 수 있도록 임시로 발급해 주는 일회용 프리패스 티켓입니다.
- **OAuth (오어스)**:
  - "구글로 로그인" 버튼처럼, 비밀번호를 직접 넘기지 않고도 다른 서비스(구글 등)에게 "이 사람이 맞다" 또는 "이 사람의 특정 데이터에 접근해도 된다"는 것을 안전하게 증명받는 표준 절차입니다.
- **액세스 토큰 (Access Token) / ID 토큰 (ID Token)**:
  - 액세스 토큰은 "이 사람의 구글 드라이브에 파일을 저장해도 된다"처럼 특정 권한을 증명하는 임시 출입증이며, ID 토큰은 "이 사람이 누구인지"만 증명하는 신분증입니다. 두 가지는 용도가 다르며 함께 쓰일 수 있습니다.
- **BaaS (Backend-as-a-Service, 백엔드 대행 서비스)**:
  - Firebase, Supabase처럼 서버·데이터베이스·로그인 기능을 회사가 직접 구축하지 않고 통째로 빌려 쓸 수 있게 해주는 서비스입니다. 식당에 비유하면 주방을 직접 짓는 대신 완비된 공유 주방을 임대하는 것과 같습니다.

## 🎬 3. 시나리오로 보는 임장기록 기술 동작 과정

실제 사용자가 앱을 쓸 때 이 기술들이 어떻게 함께 일하는지 따라가 봅시다.

```
1. [도커 & Nginx (웹 서버)]
   스마트폰 브라우저가 접속하면, Nginx가 Gzip 압축된 가벼운 HTML/CSS/JS 파일을 쏴줍니다.

2. [Vanilla JS & SPA (프론트엔드)]
   화면 깜빡임 없이 깔끔한 홈 화면이 열리고, 디자인(CSS)이 적용됩니다.

3. [Geolocation API (위치 센서)]
   "새 임장 시작"을 누르면 스마트폰의 GPS 센서가 켜지며 실시간 위도/경도를 추적합니다.

4. [Leaflet & OpenStreetMap (지도 엔진)]
   수신된 GPS 좌표를 바탕으로 지도 위에 파란색 이동 경로(폴리라인)를 실시간으로 그립니다.
   동시에 Haversine 공식이 걸어온 거리를 미터(m) 단위로 계산합니다.

5. [MediaRecorder & File API (현장 기록)]
   현장에서 마이크로 음성을 녹음하고 카메라로 사진을 찍으면,
   데이터가 Base64 텍스트로 인코딩됩니다.

6. [IndexedDB (내 폰 안의 금고)]
   네트워크가 터지지 않는 산골이나 지하에서도 모든 기록이 즉시 폰 안의 금고에 안전하게 영구 저장됩니다.

7. [향후 v2.0 클라우드 백엔드 (서버 동기화)]
   임장을 마치고 Wi-Fi가 연결되면, REST API를 통해 백엔드(PostgreSQL + PostGIS) 및
   클라우드 창고(S3)로 데이터가 백업되어 다른 기기나 배우자와 공유할 수 있게 됩니다.
```
