## 1. 서비스 개요

### 한 줄 정의

> **아파트 임장 현장의 모든 순간을 지도 위에 기록하는 위치 기반 트래킹 웹 앱**

### 배경

한국의 부동산 투자 문화에서 **임장(臨場)** — 투자 후보 단지를 직접 방문하여 현장을 확인하는 행위 — 은 필수적인 의사결정 과정이다. 그러나 임장은 대부분 개인의 기억과 단편적인 메모에 의존하고 있으며, 여러 단지를 비교하거나 과거 임장을 복기하는 데 구조화된 도구가 부재한 상황이다.

임장기록은 아웃도어 활동 기록 서비스 **Ramblr**의 스토리텔링 철학 — *"공간과 미디어의 결합"* — 을 부동산 임장이라는 구체적인 도메인에 적용하여, 단순 메모를 넘어 **공간 좌표 위에 쌓이는 현장 기록**을 만들어낸다.

## 2. 문제 정의

### 현재 임장 과정의 Pain Points

```
임장 전       임장 중              임장 후
────────      ──────────────       ─────────────
단지 선정     • 사진 촬영           • 기억 의존 복기
             • 동선 파악           • 단지 간 비교 어려움
             • 매물 정보 메모       • 자료 분산 (카메라롤,
             • 주변 인프라 확인       네이버 메모, 카카오톡)
             • 소음·조망 체크       • 재방문 시 이전 기록
                                    접근 불편
```

### 핵심 문제

| # | 문제 | 현재 대안 | 한계 |
|---|------|----------|------|
| P1 | 임장 동선과 사진이 분리됨 | 카메라 앱 | 어느 위치에서 찍었는지 알 수 없음 |
| P2 | 현장 메모가 체계화되지 않음 | 네이버 메모, 종이 | 위치 맥락 없이 텍스트만 나열 |
| P3 | 매물 정보 입력 양식이 없음 | 엑셀, 카카오톡 | 단지 간 비교 불가 |
| P4 | 현장 평가 기준이 주관적·비정형적 | 개인 노트 | 단지 간 정량 비교 불가 |
| P5 | 과거 임장 복기가 어려움 | 사진첩 스크롤 | 언제, 어디서, 무슨 생각이었는지 불명확 |

## 3. 목표 사용자

### 페르소나

#### 페르소나 A — 주거 목적 구매자 "박지수 (34세)"

- **상황**: 맞벌이 부부. 전세 만기 6개월 전 내 집 마련을 위해 첫 임장을 시작함.
- **행동**: 주말마다 2~3개 단지 방문. 배우자에게 임장 결과를 공유해야 함.
- **니즈**: 임장 내용을 나중에 남편과 함께 보기 쉽게 정리하고 싶다.
- **불편**: 사진을 찍고 나면 어느 동에서 찍었는지 기억이 안 난다.

#### 페르소나 B — 투자 목적 구매자 "이재원 (42세)"

- **상황**: 부동산 투자 경험 5년. 한 달에 4~6개 단지를 임장하며 갭투자 물건을 탐색.
- **행동**: 임장 시 매물가, 전세가, 방향, 층수를 꼼꼼히 기록. 6개월 후 재방문도 잦음.
- **니즈**: 여러 단지를 정량적으로 비교하고, 과거 임장 데이터를 빠르게 찾고 싶다.
- **불편**: 엑셀로 정리하지만 사진과 연결이 안 되고, 현장 느낌이 시간이 지나면 휘발된다.

#### 페르소나 C — 부동산 스터디 참여자 "최수현 (29세)"

- **상황**: 온라인 부동산 스터디 카페 활동 중. 임장 리포트를 작성하여 스터디원들과 공유.
- **행동**: 임장 후 블로그 포스팅이나 카카오톡 공유용 정리 자료를 제작.
- **니즈**: 지도 경로와 사진이 함께 있는 보기 좋은 임장 기록을 빠르게 만들고 싶다.
- **불편**: 사진 정리 + 동선 설명 + 평가를 따로 작성하는 데 1~2시간이 걸린다.

### 사용자 그룹 요약

| 그룹 | 주요 니즈 | 핵심 기능 |
|------|----------|----------|
| 주거 목적 구매자 | 임장 내용 정리 · 배우자 공유 | 사진+메모, 종합 메모, 기록 아카이브 |
| 투자 목적 구매자 | 매물 정보 체계화 · 단지 비교 | 매물 정보 탭, 현장 평가 점수 |
| 스터디/인플루언서 | 보기 좋은 결과물 제작 | 지도 경로, 타임라인 뷰 |

## 4. 핵심 가치 제안

### Value Proposition

> "임장 현장의 모든 순간이 지도 위에 살아있다."

기존 서비스가 제공하지 못하는 **세 가지 차별점**:

```
1. 공간 연결성
   모든 기록(메모·사진·매물정보·평가·음성)이
   GPS 좌표와 즉시 연결됨.
   → "어디에서" 그 판단을 했는지 언제나 확인 가능.

2. 임장 전용 기록 양식
   부동산 임장에 특화된 입력 필드(동·층·평형·매매가·전세가·방향)와
   평가 항목(교통·학군·편의시설·소음·주차·일조량·조망) 제공.
   → 범용 메모 앱 대비 구조화된 데이터 축적.

3. 시간이 지나도 생생한 복기
   이동 경로 + 기록 타임라인이 결합된 상세 뷰로
   몇 달 후에도 그날의 동선과 판단을 재현 가능.
```

## 5. 서비스 범위 및 기능 정의

### 기능 맵

```
임장기록
├── 기록 (Record)
│   ├── 임장 세션 시작/종료
│   ├── GPS 경로 추적
│   └── 현장 기록 추가
│       ├── 메모
│       ├── 사진
│       ├── 매물 정보
│       ├── 현장 평가
│       └── 음성 메모
│
├── 관리 (Manage)
│   ├── 임장 목록 검색
│   ├── 임장 상세 보기
│   │   ├── 경로 지도 재현
│   │   └── 기록 타임라인
│   └── 기록/세션 삭제
│
└── [v2 예정] 분석 및 공유 (Analyze & Share)
    ├── 단지 간 평가 비교
    ├── 임장 리포트 PDF 내보내기
    └── 공유 링크 생성
```

| F02 | 메모 기록 | 위치 기반 텍스트 메모 |
| F03 | 사진 기록 | 카메라/갤러리 사진 + 위치 태깅 |

| F07 | 임장 완료 | 별점·종합 메모 저장 |
| F08 | 기록 아카이브 | 목록 조회 및 검색 |

## 6. 사용자 여정

### 주요 시나리오: 주말 임장 1회

```
[준비 단계]
사용자가 임장할 단지 사전 조사 완료
→ 앱 실행 → "새 임장 시작"
→ 단지명 입력 (래미안원베일리)
→ GPS 권한 허용 → 추적 시작

[현장 탐색 - 단지 외부]
이동 중 경로 자동 기록
→ 정문 도착: 📸 사진 (정문, 경비실)
→ 주차장: 📝 메모 ("지하 2층, 세대당 1.5대")
→ 단지 외곽 한 바퀴: 경로 폴리라인 그려짐

[현장 탐색 - 특정 매물 확인]
해당 동 앞 도착
→ 🏠 매물 정보 입력 (101동 15층 84㎡ 15억5천 남향)
→ 조망 사진 촬영: 📸 사진 (산 뷰 확인)
→ 주변 소음 확인 중 음성 메모: 🎙️ "공사 소음 없음, 조용함"

[주변 인프라 확인]
도보로 이마트 방향 이동
→ ⭐ 현장 평가 입력 (교통4 학군3 편의시설5 소음4 주차4 일조량5 조망4)
→ 평가 메모: "초등학교까지 도보 8분, 마트 3분"

[임장 완료]
"완료" 버튼 탭
→ 총평 ⭐⭐⭐⭐ 선택
→ 종합 메모: "가격 대비 생활 편의성 우수. 소음 걱정 없음. 전세가율 52%."
→ 저장 → 상세 뷰 자동 이동

[복기 / 공유]
배우자에게 스마트폰 화면 보여주며 타임라인 설명
→ 지도 위 마커를 탭하며 현장 사진·메모 공유
```

### 여정 내 감정 곡선

```
감정
 ↑
😊 ───┐ 시작 기대감
      │
 →    ├── GPS 잡히는 동안 대기 (약간 불안)
      │
😊 ───┤ 경로 그려지는 것 확인 → 만족
      │
 →    ├── 기록 추가 탭 전환 학습 (초기 1회)
      │
😊 ───┤ 매물 정보 입력 완료 → 안도
      │
🤩 ───┘ 상세 뷰에서 전체 여정 확인 → 성취감
```

## 7. 화면 구성 (IA)

```
앱
├── 홈 (/)
│   ├── 통계 카드 (총 임장 수, 총 이동 거리)
│   ├── 새 임장 시작 CTA
│   └── 최근 임장 목록 (최대 5개)
│
├── 기록 (/records)
│   ├── 단지명 검색
│   └── 전체 세션 목록 (최신순)
│
├── 추적 (/track) [임장 중에만 접근 가능]
│   ├── 단지명 + 경과 시간 + 이동 거리 헤더
│   ├── 실시간 지도 (경로 + 현재 위치)
│   ├── 기록 추가 모달
│   │   ├── 메모 탭
│   │   ├── 사진 탭
│   │   ├── 매물 탭
│   │   ├── 평가 탭
│   │   └── 음성 탭
│   └── 하단 컨트롤 (기록 추가 / 일시정지 / 완료)
│
└── 상세 (/detail/:id)
    ├── 전체 경로 지도 (시작점 S, 종료점 E, 마커)
    ├── 통계 (거리 / 시간 / 기록 수 / 별점)
    ├── 종합 메모
    └── 기록 타임라인 (시간순)
        └── 마커 상세 팝업 (탭 시)
```

## 8. 경쟁 서비스 분석

### 직접 경쟁: 부동산 앱

| 서비스 | 강점 | 임장 기록 기능 |
|--------|------|--------------|
| 네이버 부동산 | 시세·매물 정보 풍부 | 없음 |
| 직방 | 단지 정보 상세 | 없음 |
| 호갱노노 | 실거래가 분석 | 없음 |
| 아실 | 갭투자 데이터 | 없음 |

→ 현재 부동산 앱 중 **현장 기록에 특화된 서비스는 전무**하다.

### 간접 경쟁: 메모 · 기록 앱

| 서비스 | 강점 | 한계 (임장 관점) |
|--------|------|----------------|
| 네이버 메모 | 간편한 텍스트 입력 | 위치 연동 없음, 비정형 |
| 노션 | 유연한 DB 구조 | 현장 입력 UX 불편, 위치 없음 |
| 에버노트 | 첨부 파일 지원 | 지도 연동 없음 |

### 간접 경쟁: 위치 기반 기록 앱

| 서비스 | 강점 | 한계 (임장 관점) |
|--------|------|----------------|
| Ramblr | 지도+미디어 스토리텔링 | 부동산 전용 입력 양식 없음 |
| Strava | 운동 경로 추적 | 부동산과 무관 |
| Google Maps (저장 장소) | 위치 저장 용이 | 경로 기록·매물 데이터 없음 |

### 포지셔닝

```
           위치 기반 기록 강도
                  ↑
           Ramblr │ 임장기록 ← 목표 포지션
                  │
 ──────────────────┼──────────────────────→ 부동산 도메인 전문성
    네이버 메모    │  네이버 부동산
    노션           │  직방
                  │
```

## 9. 비즈니스 모델

현재 v1.0은 **무료 오픈소스** 형태로 배포되며, 향후 다음 수익 모델을 검토한다.

### v2.0 Freemium 모델 (검토안)

| 티어 | 가격 | 주요 기능 |
|------|------|----------|
| Free | 무료 | 임장 5회/월, 마커 20개/세션, 로컬 저장 |
| Plus | 월 4,900원 | 무제한 임장, 클라우드 동기화, PDF 내보내기 |
| Team | 월 9,900원 | Plus 기능 + 팀원 3명 공유, 공동 편집 |

### 잠재 수익원

- **구독료**: Plus/Team 티어
- **B2B 라이선스**: 공인중개사·부동산 법인 대상 팀 플랜
- **데이터 인사이트**: 익명화된 임장 패턴 분석 리포트 (기관 투자자 대상)

## 10. 성공 지표

### 핵심 KPI

| 지표 | 정의 | v1.0 목표 |
|------|------|----------|
| 임장 완료율 | 시작된 세션 중 완료된 세션 비율 | ≥ 70% |
| 세션당 마커 수 | 임장 1회에 추가된 평균 기록 수 | ≥ 4개 |
| 재방문율 | 1회 사용 후 재사용 비율 (7일 기준) | ≥ 40% |
| 임장 기록 보존율 | 삭제하지 않고 유지되는 세션 비율 | ≥ 85% |

### 정성 지표

- 사용자 인터뷰: "임장 후 복기가 편해졌다" 응답 비율
- 배우자·동반인에게 앱 화면을 보여준 경험 비율
- 과거 임장 기록을 재열람한 빈도

## 11. 기술 제약 및 리스크

| 리스크 | 영향도 | 대응 방안 |
|--------|--------|----------|
| GPS 실내 신호 약함 | 높음 | 일시정지 기능 제공, 정확도 50m 필터 적용 |
| 사진 용량 → IndexedDB 한도 초과 | 중간 | v1.1에서 클라이언트 측 리사이즈 도입 |
| HTTPS 없는 환경에서 GPS/카메라 비활성 | 높음 | 배포 시 HTTPS 필수 명시, 가이드 문서 제공 |
| 브라우저 캐시 초기화 → 데이터 소실 | 높음 | v2.0 클라우드 동기화로 해소, 현재는 경고 문구 제공 |
| iOS Safari MediaRecorder 미지원 이슈 | 중간 | 음성 탭에서 지원 여부 감지 후 안내 메시지 표시 |
