## 1. 앱 실행하기

### Docker Compose로 실행 (권장)

Docker 환경이 준비되어 있다면 명령어 한 줄로 정적 웹 서버를 기동할 수 있습니다.

```bash
# 저장소 클론
git clone https://github.com/your-username/imgangr.git
cd imgangr/docker

# 컨테이너 빌드 및 백그라운드 실행
docker compose up -d

# 브라우저 접속
# → http://localhost:8080
```

포트를 변경하여 실행하려면 `PORT` 환경변수를 지정합니다:

```bash
PORT=3000 docker compose up -d
# → http://localhost:3000
```

### 로컬 직접 실행

별도의 빌드 과정 없이 `web/` 디렉터리의 정적 파일을 로컬 HTTP 서버로 즉시 띄울 수 있습니다.

```bash
cd imgangr/web

# Python 3 내장 서버 사용 시
python3 -m http.server 8080

# 또는 Node.js npx serve 사용 시
npx serve . -p 8080

# 브라우저 접속
# → http://localhost:8080
```

### 스마트폰에서 접속하기 (HTTPS 필수)

> ⚠️ **중요 (보안 컨텍스트)**:
> 브라우저의 **GPS(위치 추적)** 및 **마이크(음성 녹음)** 기능은 W3C 보안 규격상 **HTTPS** 또는 `localhost`에서만 활성화됩니다.
> 같은 Wi-Fi 대역의 사설 IP(`http://192.168.x.x:8080`)로 모바일에서 접속할 경우 권한 요청이 차단됩니다.

**모바일 테스트 방법:**
1. **Cloudflare Tunnel / ngrok 활용 (가장 추천)**:
   ```bash
   ngrok http 8080
   # 출력되는 https://xxxx.ngrok-free.app 주소로 스마트폰 브라우저 접속
   ```
2. **Reverse Proxy (Caddy / Nginx)에 SSL 인증서 적용**:
   상세 배포 방법은 [docs/backend.md](backend.md)를 참고하세요.

## 2. 홈 화면

앱의 첫 화면에는 누적 통계와 최근 임장 기록이 표시됩니다.

```
┌─────────────────────────────┐
│ 🏘️ 임장기록                  │
│ 아파트 임장을 스마트하게      │
│                              │
│  [총 임장 횟수]  [총 이동거리] │
├─────────────────────────────┤
│  📍 새 임장 시작              │  ← 탭하면 시작 모달
├─────────────────────────────┤
│  최근 임장 기록               │
│  ┌──────────────────────┐   │
│  │ 강남구                  │   │
│  │ 2026.03.17  ⭐⭐⭐⭐  │   │
│  │ 🚶 1.2km  ⏱ 45분  📍 6│   │
│  └──────────────────────┘   │
└─────────────────────────────┘
```

- **통계 카드**: 누적 임장 횟수와 총 이동 거리를 실시간 합산하여 표시합니다.
- **새 임장 시작**: 터치 시 임장 세션 시작 모달을 엽니다.
- **최근 임장 기록**: 최신 5건의 세션 카드가 노출되며, 터치 시 상세 화면으로 이동합니다.

---

## 3. 임장 시작하기

1. 홈 화면의 **`📍 새 임장 시작`** 버튼을 누릅니다.
2. 팝업에서 **지역명(구 단위)**을 입력합니다. (예: `강남구`, `마포구`, `분당구`)
   > 💡 임장의 관리 단위는 **구(區)** 입니다. 한 번의 임장 세션 동안 해당 구의 여러 아파트 단지를 순회하게 되며, 개별 단지 정보는 이동 중 마커로 등록합니다.
3. **`시작하기 📍`** 버튼을 누릅니다.
   - 브라우저 위치 권한 허용 팝업이 뜨면 반드시 **허용**을 선택합니다.
4. 추적 화면(`view-track`)으로 이동하며, 현재 위치를 중심으로 실시간 GPS 이동 경로가 지도 위에 파란 선으로 그려집니다.

## 4. 임장 진행 중 — 현장 기록 추가

임장 중 특정 단지나 위치에 도달하면 화면 하단의 **`+ 기록 추가`** 버튼을 누릅니다. 5개 탭 중 원하는 기록을 선택하여 저장할 수 있습니다.

### 메모 (📝)
- 현장의 즉각적인 관찰 내용(경비실 운영, 주변 도로 소음, 상권 분위기 등)을 텍스트로 자유롭게 기록합니다.

### 사진 (📸)
- 카메라로 직접 촬영하거나 갤러리에서 사진을 선택합니다 (복수 선택 지원).
- 사진 미리보기를 확인하고 간단한 캡션을 덧붙여 위치와 함께 보관합니다.

### 매물 정보 (🏠)
- 방문한 단지의 상세 매물 정보를 구조화하여 기록합니다.
- 입력 필드: **단지명(필수)**, 동, 층, 평형(㎡), 매매가, 전세가, 방향, 특이사항

### 현장 평가 (⭐)
- 7대 핵심 항목(교통, 학군, 편의시설, 소음, 주차, 일조량, 조망)을 1~5점 슬라이더로 신속하게 채점합니다.
- 평가 메모를 함께 남겨 나중에 점수의 근거를 복기할 수 있습니다.

### 음성 메모 (🎙️)
- 걷거나 이동 중 텍스트 입력이 번거로울 때 유용합니다.
- `🎙️ 녹음 시작` 버튼을 누르고 음성으로 현장 소감을 말한 뒤, `⏹ 녹음 중지`를 눌러 저장합니다.

## 5. 임장 완료하기

1. 임장이 끝나면 추적 화면 하단의 **`완료`** 버튼을 누릅니다.
2. 완료 모달에서 다음 정보를 입력합니다:
   - **총평 (별점)**: 0~5점 별점 평가
   - **종합 메모**: 해당 구 전체 임장에 대한 종합 결론 및 투자 판단
3. **`저장 완료 ✓`** 버튼을 누르면 세션이 마감되고 상세 보기 화면으로 이동합니다.
   - 잠시 쉬어가거나 카페/식당에 머무를 때는 **`일시정지`** 버튼을 눌러 GPS 수집을 멈출 수 있습니다.

---

## 6. 기록 목록 보기

- 하단 네비게이션의 **`기록`** 탭을 누르면 과거의 모든 임장 세션이 최신순으로 나열됩니다.
- 상단 검색창에 지역명을 입력하면 실시간으로 검색 필터링이 동작합니다.
- 각 카드의 `🗑️` 아이콘을 누르면 세션과 관련된 모든 경로 및 마커 데이터를 안전하게 삭제할 수 있습니다.

---

## 7. 임장 상세 보기

- 세션 카드를 클릭하면 상세 화면(`view-detail`)이 열립니다.
- **경로 지도**: 시작 지점(S)부터 종료 지점(E)까지의 전체 동선과, 기록이 생성된 지점에 5가지 타입별 컬러 핀이 표시됩니다.
- **상세 통계**: 총 이동거리, 소요시간, 기록 수, 종합 별점이 한눈에 요약됩니다.
- **기록 타임라인**: 시간순으로 현장에서 남긴 메모, 사진, 매물 정보, 평가 점수, 음성 녹음이 정렬됩니다.
- 마커 핀이나 타임라인 항목을 누르면 바텀시트 팝업이 열려 상세 내용을 확인하고 개별 삭제할 수 있습니다.

## 8. 권한 설정

| 권한 | 필수 여부 | 사용 목적 | 비활성화 시 영향 |
|------|-----------|-----------|------------------|
| **위치 (GPS)** | **필수** | 실시간 이동 동선 수집, 마커 좌표 매핑 | 경로 추적 불가, 지도 중심 이동 불가 |
| **마이크** | 선택 | 음성 메모 녹음 | 음성 메모 기능 사용 불가 |
| **카메라 / 파일** | 선택 | 현장 사진 촬영 및 첨부 | 사진 업로드 불가 |

브라우저 주소창 좌측의 설정/자물쇠 아이콘을 클릭하여 언제든지 권한을 재설정할 수 있습니다.

## 9. 주의 사항 및 팁

1. **오프라인 우선 저장**: 모든 데이터는 기기 브라우저의 `IndexedDB`에 안전하게 보관됩니다. 단, 브라우저의 "방문 기록/사이트 데이터 삭제" 시 함께 지워질 수 있으니 유의하세요.
2. **GPS 오차 관리**: 지하 주차장이나 고층 빌딩 사이에서는 일시적으로 GPS 신호가 튈 수 있습니다. 앱 자체에 50m 초과 노이즈 필터와 3m 최소 이동 필터가 내장되어 있어 안정적인 경로를 유지합니다.
3. **배터리 관리**: 고정밀 GPS(`enableHighAccuracy`) 연속 사용은 배터리 소모량이 큽니다. 장시간 임장 시에는 화면 밝기를 조절하고 보조 배터리를 지참하는 것을 권장합니다.
4. **기술 아키텍처 참고**:
   - 프론트엔드 모듈 구현 상세: [docs/frontend.md](frontend.md)
   - 서버 인프라 및 v2 백엔드 설계: [docs/backend.md](backend.md)
