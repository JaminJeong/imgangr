## 1. 앱 실행하기

### 로컬에서 실행

```bash
# 저장소 클론
git clone https://github.com/your-username/imgangr.git
cd imgangr

# 내장 HTTP 서버 실행 (Python 3)
python3 -m http.server 8080

# 브라우저에서 접속
# → http://localhost:8080
```

> **Python이 없다면** Node.js의 `npx serve` 또는 VS Code의 **Live Server** 확장을 사용해도 됩니다.
>
> ```bash
> npx serve .          # Node.js
> ```

### 스마트폰에서 접속

같은 Wi-Fi에 연결된 상태에서 PC의 로컬 IP로 접속합니다.

```bash
# PC의 로컬 IP 확인
ip addr show | grep 'inet ' | awk '{print $2}'

# 예) PC IP가 192.168.1.5 라면 스마트폰에서
# → http://192.168.1.5:8080 접속
```

> GPS·카메라·마이크는 **HTTPS 또는 localhost**에서만 작동합니다.
> 스마트폰에서 전체 기능을 사용하려면 HTTPS 서버가 필요합니다.

## 2. 홈 화면

앱 첫 화면에는 두 가지 정보가 표시됩니다.

```
┌─────────────────────────────┐
│ 🏘️ 임장기록                  │
│ 아파트 임장을 스마트하게      │
│                              │
│  [총 임장 횟수]  [총 이동거리] │
├─────────────────────────────┤
│  📍 새 임장 시작              │  ← 탭하면 시작 모달
├─────────────────────────────┤
│  최근 임장 기록               │
│  ┌──────────────────────┐   │
│  │ 래미안원베일리          │   │
│  │ 2026.03.17  ⭐⭐⭐⭐  │   │
│  │ 🚶 1.2km  ⏱ 45분  📍 6│   │
│  └──────────────────────┘   │
└─────────────────────────────┘
```

- 통계 카드: 지금까지의 총 임장 횟수와 누적 이동 거리를 보여줍니다.
- 최근 기록 카드를 탭하면 해당 임장의 상세 화면으로 이동합니다.

## 3. 임장 시작하기

**홈 → `📍 새 임장 시작` 버튼 탭**

1. 단지명 입력 창이 나타납니다.

   ```
   단지명 *
   [ 예) 래미안원베일리, 아크로리버파크  ]
   ```

2. 단지명을 입력하고 **시작하기 📍** 를 탭합니다.
   - 처음 실행 시 브라우저가 **위치 권한**을 요청합니다. 반드시 **허용**해야 합니다.

3. 지도 화면으로 전환되며 GPS 추적이 시작됩니다.

   ```
   ┌─────────────────────────────┐
   │ 래미안원베일리   경과 00:03  이동 12m │
   ├─────────────────────────────┤
   │                             │
   │   [지도 - 이동 경로 표시]    │
   │         🔵 (현재 위치)      │
   │                             │
   ├─────────────────────────────┤
   │ [+ 기록 추가]  [일시정지]  [완료] │
   └─────────────────────────────┘
   ```

   - 파란 점이 현재 위치이며, 이동하면 경로(폴리라인)가 그려집니다.
   - 상단에 경과 시간과 이동 거리가 실시간으로 업데이트됩니다.

## 4. 임장 진행 중 — 현장 기록 추가

**`+ 기록 추가` 버튼 탭** → 5가지 탭 중 선택

### 메모

현장에서 즉시 텍스트를 남깁니다.

| 항목 | 설명 |
|------|------|
| 현장 메모 | 자유 형식 텍스트. 주변 소음, 공사 현황, 관리 상태 등 |

**예시 활용**
```
"정문 경비원 상주. 택배 보관함 충분.
 놀이터 리모델링 예정(관리소 확인).
 옆 단지 공사 소음 — 오후 2시 기준 체감 보통."
```

---

### 사진

현장 사진을 위치와 함께 기록합니다.

1. `📷 사진 촬영 / 갤러리 선택` 영역을 탭합니다.
2. 카메라로 직접 촬영하거나 갤러리에서 선택합니다. (복수 선택 가능)
3. 선택한 사진 썸네일이 미리보기로 표시됩니다.
4. **사진 설명** 필드에 촬영 맥락을 간단히 적습니다.

**예시 설명**
- `남향 거실 조망`
- `지하 주차장 입구 폭`
- `단지 내 어린이집 위치`

---

### 매물 정보

방문한 특정 동·호의 매물 정보를 기록합니다.

| 필드 | 입력 예시 |
|------|-----------|
| 동 | `101` |
| 층 | `15` |
| 평형 (㎡) | `84` (전용면적 기준 입력 권장) |
| 방향 | 남향 / 남동향 / 남서향 / 동향 / 서향 / 북향 |
| 매매가 | `15억 5,000` |
| 전세가 | `8억` |
| 특이사항 | `수리 없이 입주 가능. 로얄층.` |

---

### 현장 평가

항목별 슬라이더(1~5점)로 단지를 평가합니다.

| 항목 | 평가 기준 예시 |
|------|--------------|
| 교통 | 지하철역까지 도보 시간, 버스 노선 수 |
| 학군 | 배정 초등학교 학업 수준, 학원가 근접성 |
| 편의시설 | 마트·병원·카페·공원의 접근성 |
| 소음 | 도로·철도·공사 소음 체감 정도 |
| 주차 | 세대당 주차 대수, 외부 차량 통제 여부 |
| 일조량 | 낮 시간대 햇빛 유입 정도 |
| 조망 | 산·강·도심 뷰 또는 조망 막힘 여부 |

평가 후 **평가 메모** 필드에 이유를 간략히 적으면 나중에 복기하기 좋습니다.

---

### 음성 메모

양손이 바쁜 상황에서 빠르게 음성으로 현장을 기록합니다.

1. `🎙️ 녹음 시작` 버튼을 탭합니다.
   - 처음 실행 시 브라우저가 **마이크 권한**을 요청합니다. 반드시 **허용**해야 합니다.
2. 원하는 내용을 말합니다.
3. `⏹ 녹음 중지` 버튼을 탭합니다.
4. 재생 바가 나타나며 녹음을 확인할 수 있습니다.
5. **기록 저장** 버튼으로 저장합니다. 다시 녹음하려면 `🎙️ 다시 녹음` 버튼을 탭합니다.

## 5. 임장 완료하기

**`완료` 버튼 탭** → 완료 모달 진입

```
┌──────────────────────────┐
│ 임장 완료                │
│                          │
│ 총평 (별점)               │
│  [──────────●──] ⭐⭐⭐  │
│                          │
│ 종합 메모                 │
│ [                      ] │
│ [  이번 임장의 결론 입력  ] │
│                          │
│ [계속 임장]  [저장 완료 ✓] │
└──────────────────────────┘
```

- **총평**: 슬라이더로 0~5점 별점을 선택합니다.
- **종합 메모**: 이번 임장의 전반적인 결론이나 투자 판단을 기록합니다.
- **저장 완료** → 기록이 저장되고 상세 화면으로 자동 이동합니다.
- **계속 임장** → 모달을 닫고 추적 화면으로 돌아갑니다.

> `일시정지` 버튼으로 GPS 추적을 잠시 멈출 수 있습니다 (식사, 내부 관람 시 유용).
> 일시정지 중에도 기록 추가는 가능합니다.

## 6. 기록 목록 보기

하단 네비게이션 **기록** 탭 탭

```
┌─────────────────────────────┐
│ 📚 임장 기록                 │
│ [ 단지명으로 검색…           ] │
├─────────────────────────────┤
│ 래미안원베일리                │
│ 2026.03.17 14:30  🗑️        │
│ 🚶 1.2km  ⏱ 45분  📍 6개  ⭐⭐⭐⭐ │
│ "전반적으로 관리 상태 양호…" │
├─────────────────────────────┤
│ 아크로리버파크               │
│ 2026.03.15 10:00  🗑️        │
│ 🚶 0.8km  ⏱ 30분  📍 3개  ⭐⭐⭐ │
└─────────────────────────────┘
```

- 검색창에 단지명을 입력하면 실시간으로 필터링됩니다.
- 🗑️ 버튼으로 기록을 삭제할 수 있습니다 (확인 창이 나타납니다).
- 카드를 탭하면 상세 화면으로 이동합니다.

```
├─────────────────────────────┤

├─────────────────────────────┤

│  여유 있음. 학군 재확인 필요" │
├─────────────────────────────┤
│ 현장 기록 타임라인            │
│ ┌──────────────────────┐   │
│ │ 📝 메모     14:32    │   │
│ │ 정문 경비원 상주…     │   │
│ ├──────────────────────┤   │
│ │ 🏠 매물     14:45    │   │

│ └──────────────────────┘   │
└─────────────────────────────┘
```

### 마커 상세 보기

타임라인 항목 또는 지도 위 마커를 탭하면 팝업이 열립니다.

- **메모**: 전체 텍스트 표시
- **사진**: 원본 사진 + 설명
- **매물**: 표 형태로 입력 정보 전체 표시
- **평가**: 항목별 막대 그래프
- **음성**: 재생 버튼으로 즉시 청취

팝업 내 **🗑️ 삭제** 버튼으로 해당 기록만 개별 삭제할 수 있습니다.

## 8. 권한 설정

| 권한 | 필요 기능 | 브라우저 설정 경로 |
|------|----------|-----------------|
| 위치 (GPS) | 경로 추적, 마커 위치 태깅 | 주소창 자물쇠 아이콘 → 위치 허용 |
| 카메라 | 사진 촬영 | 주소창 자물쇠 아이콘 → 카메라 허용 |
| 마이크 | 음성 메모 녹음 | 주소창 자물쇠 아이콘 → 마이크 허용 |

권한을 거부한 경우, 브라우저 설정 → 해당 사이트 → 권한 항목에서 다시 허용할 수 있습니다.

## 9. 주의 사항

- **데이터 백업 없음**: 모든 기록은 브라우저 IndexedDB에만 저장됩니다. 브라우저 캐시 초기화 시 데이터가 삭제될 수 있습니다.
- **사진 용량**: 고화질 사진을 대량 첨부하면 브라우저 저장 한도에 가까워질 수 있습니다.
- **실외 GPS 정확도**: 건물 내부나 지하에서는 GPS 신호가 불안정할 수 있습니다. 실내에서는 일시정지를 권장합니다.
- **배터리 소모**: GPS 연속 사용은 배터리를 빠르게 소모합니다. 장시간 임장 시 보조배터리를 준비하세요.
